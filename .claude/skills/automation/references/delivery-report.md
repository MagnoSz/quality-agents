# Delivery and traceability report

Saved as `delivery-report.md` in the run's outputs folder.

## Sections

1. **Summary** — mode, scope delivered, overall result.
2. **Sources** — documentation consulted (title, id/URL, section) and capabilities used.
3. **Changes in the target repository** — files created/changed (paths), per layer; commits/branch if the user asked for them.
4. **Traceability matrix**:

   | FLX scenario (id) | Oracle item | Test (file › test name) | Verification | Last result |
   |---|---|---|---|---|

5. **Execution results** — command, environment, date/time, pass/fail/blocked counts, executed by (agent or user). Link to evidence (reports, traces, screenshots) in the run's evidence folder.
6. **Failures and diagnoses** — classification (product defect / test defect / environment-data), evidence, action taken or recommended. Suspected product defects are not worked around.
7. **Not automated** — oracle items or scenarios not automated, with reasons.
8. **Pending items and risks.**
9. **Proposed context updates** — conventions or knowledge to offer to `project-context`.
